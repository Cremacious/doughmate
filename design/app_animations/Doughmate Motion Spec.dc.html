Motion spec · Fresh Bake v3
Doughmate, in motion
Six transitions, each shown as the app behaves today beside what it should do. Both columns loop in step. Every proposed move lands inside 240ms, uses a token that already exists in theme.ts, and falls back to a 120ms fade under reduced motion.
Principle 01
Nothing waits on motion
A tap commits immediately. The animation describes what just happened, it never gates it.
Principle 02
One move per event
Position or opacity, rarely both at full strength. Two competing moves read as lag, not polish.
Principle 03
Short in, shorter out
Entering earns 220ms. Leaving gets 120 to 170. Dismissing something should feel like it already went.

What changes
spring.soft becomes a new spring.snap, 420 stiffness and 26 damping. It settles in about 240ms and keeps a 2px overshoot, so the panel still reads as a physical thing arriving.
Scrim fades over 140ms instead of appearing at once, which is what currently makes the sheet feel like it lags behind its own background.

What changes
Card already has HardShadow. It just needs the Pressable to pass pressed through, so the tap has an answer before the sheet has moved at all.
The list scales to 0.965 and drops to 72% over 220ms. That is the depth cue the transparentModal never got, and it makes the sheet read as on top rather than merely newer.

06
Sam, idling
Sam is drawn in react native svg and he has never moved. Until the Lottie files land, three looping shared values give him a pulse: a slow breath, a slower sway, and a blink on an offbeat. No new dependency, and it is the cheapest thing on this page.
Today
no motionstatic svg
Proposed
breath 2100ms · sway 4200msblink offbeat
What changes
Breath is a 2100ms scale to 1.025 with a 2.5 unit rise, anchored at his base so he squashes rather than floats.
Sway is 4200ms and 1.6 degrees, deliberately not a multiple of the breath, so the loop never lands on the same pose twice in a row.
Blink is a 90ms scaleY on the eye group only. It reads as alive and costs one shared value.
Only the large Sams idle: onboarding, empty states, the starter hero. The 30px footnote Sam and the 34px tip Sam stay still, or the screen twitches.
// src/components/Sam.tsx export function Sam({ size = 96, idle = false, ... }) { const reduced = useReducedMotion(); const live = idle && !reduced && size >= 56; const breath = useSharedValue(0); const sway = useSharedValue(0); const blink = useSharedValue(1); useEffect(() => { if (!live) return; breath.value = withRepeat( withTiming(1, { duration: 2100 }), -1, true); sway.value = withRepeat( withTiming(1, { duration: 4200 }), -1, true); blink.value = withRepeat( withSequence( withDelay(2300, withTiming(0.08, { duration: 45 })), withTiming(1, { duration: 45 })), -1, false); }, [live]); }
Handoff
Six edits, in this order
1 · src/theme.ts
Add spring.snap. Change press to downMs 90 and upMs 160. Nothing else in the token file moves, so every screen inherits the new feel without touching a screen.
2 · src/ui/HardShadow.tsx
Asymmetric press timing. One file, and Button, Chip, ModeChip, IconButton, Card and the FAB all snap. This is the change you feel most for the least code.
3 · src/ui/BottomSheet.tsx
spring.snap, a 140ms scrim, a 170ms dismiss, and the optional recede for the layer below. Covers the tray, all the option sheets, recipe and starter detail, and the paywall.
4 · app/(tabs)/_layout.tsx + TabBar
Tab transitionSpec at 220ms, and the pill becomes one spring driven shared element instead of four conditional fills.
5 · OnboardingScaffold + its layout
Stack animation off, content animates instead, dots morph. Only the first run sees it, which also makes it the safest place to land the pattern.
6 · src/components/Sam.tsx
The idle prop. Last, because it is the only item here that is decoration rather than feedback, and it is the one to drop if the Lottie files arrive first.
Reduced motion
Every item above keeps the existing rule: useReducedMotion swaps the move for a 120ms opacity fade, and press falls back to opacity 0.9. The recede layer and Sam's idle switch off entirely rather than shortening.
Cost
All of it is transform and opacity on the UI thread through reanimated 4. No layout animations, no new dependency, no change to any engine in src/lib. The pure tests stay green because nothing they cover is touched.
Not in this pass
List add, delete and undo; the convert result PopIn, which is already right; cook mode step advance; the timer pill. Say the word and they get the same treatment.
